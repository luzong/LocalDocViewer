## 🏗️ 核心机制：自动建站系统（源码独有重点）

**本项目最大特色：无需手动搭建前端页面**

首次扫描检测输出目录无网站结构时，自动按 **优先级检索模板目录**：

`scanner/data > site > site_template`

自动复制：`index.html`、css、js 等所有前端静态资源，**自动生成完整可浏览站点**。

非首次扫描只会更新数据与缩略图，不会重复覆盖模板文件。

- 固定封面尺寸：`400 × 560` 书籍比例
- 文本预览：最多 22 行，单行最大 60 字符截断
- **渲染页数上限**：UI组件与内核逻辑完全统一，固定区间 **1-10页**，无参数冲突、无虚假上限问题
- 多页命名规则：`xxx.png、xxx_2.png、xxx_3.png ...`

## 🧹 一键缓存重置（v3 优化功能）

- **Windows（装Office+pywin32）**：Word/PPT 可转PDF高清真实页面预览
- **Windows（无Office）/ Mac / Linux**：Word/PPT 仅文本降级预览，无法渲染真实页面
- **MOBI/AZW3**：仅文字提示预览，无封面解析
